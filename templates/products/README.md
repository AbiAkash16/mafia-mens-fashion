
# MAFIA — Men's Fashion E-Commerce Website

## About the Project
MAFIA is a men's fashion e-commerce website built using Django.
It allows users to explore clothing products, create accounts,
log in, manage their shopping cart, and place orders.

## Technologies Used
- Frontend: HTML, CSS
- Backend: Python, Django
- Database: MySQL
- Development Tool: Visual Studio Code

## Features
- User registration and login
- Product listings and product details
- Product categories and search
- Shopping cart management
- Checkout and order placement
- Order history
- Responsive fashion-themed interface

## Installation

1. Clone or download this project.
2. Open the project folder in VS Code.
3. Create and activate a Python virtual environment.
4. Install Django and the required dependencies.
5. Configure your database in Django settings.
6. Run database migrations.
7. Start the development server.

## Run the Project

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
